# Nikhilesh Babu MT — Portfolio

A React and Vite portfolio presenting Nikhilesh's backend engineering work, experience, skills, education, and contact details.

## Local development

```sh
npm install
npm run dev
```

Run `npm run build` and `npm run lint` before publishing. Vite is configured for the GitHub Pages path `/nikhilesh-portfolios/`.

## Content and assets

- Portfolio content: `src/App.jsx`
- Styling and responsive layout: `src/App.css`
- Edited portrait: `public/images/nikhilesh-portrait.png`
- Original work photo: `public/images/nikhilesh-at-work.jpg`
- Downloadable résumé: `public/documents/Nikhilesh_Babu_Resume.pdf`

The hero portrait was AI edited from Nikhilesh's supplied photo to preserve his likeness while creating a consistent studio look.
